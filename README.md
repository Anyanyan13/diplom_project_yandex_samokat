# Тест на проверку возможности получения данных о заказе по его трек-номеру в Яндекс Самокат с помощью API Яндек Самокат И SQL-запросы к базе данных

Проект содержит автоматизированный тест, который проверяет сценарий
работы с заказом в сервисе Яндекс.Самокат:
1. Клиент создаёт заказ (`POST /api/v1/orders`).
2. По полученному треку запрашивается информация о заказе (`GET /api/v1/orders/track`).
3. Проверяется, что данные о заказе успешно возвращаются и соответствуют ожиданиям.

- Для запуска тестов должны быть установлены пакеты pytest и requests
- Запуск всех тестов выполняется командой pytestсоздать

Также в проекте содержаться SQL-запросы к базе данных, проверяющие отображение созданного заказа в БД и корректность статусов заказов в БД
